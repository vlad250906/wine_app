# Оценка качества вина

## Кэширование

- [`st.cache_resource`](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_resource) хранит один экземпляр загруженной модели на процесс Streamlit. Все сеансы используют этот экземпляр при повторных запусках скрипта.
- [`st.cache_data`](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_data) хранит таблицу из `test.csv` и массив вероятностей класса 1. При обращении к кэшу Streamlit возвращает копию данных, поэтому изменения в одном сеансе не затрагивают другие. В ключ кэша вероятностей входят признаки тестовой выборки. Аргумент `_model` исключён из хеширования, а порог применяется уже к готовым вероятностям.

Без декоратора `joblib.load` при каждом повторном запуске скрипта, в том числе при движении ползунка, заново прочитает файл с диска и создаст новый объект модели. Это добавит задержку на чтение и десериализацию.
